Cognitive Dynamics Studio

Four different ways of modeling cognition.

Explore four interactive computational interpretations through large, visual simulations. Pause them, step through their states, change speed, inspect live metrics, or open a model fullscreen.

01 · Live simulation studio

See all four simulations

Each model has a distinct visual language. The color identifies the model, while the state panel explains what is happening.

02 · How they work

What each visualization actually models

CAUSAL–DETERMINIST

Follow a chain

Seven explicit states form a directional chain. Step advances exactly one state; playback uses the same transition.

DIALECTICAL–ALGORITHMIC

Hold opposites together

Thesis and antithesis converge on contradiction, then move through synthesis, rule formation and algorithmic iteration.

HOLOGRAPHICAL–PANORAMIC

Change the viewpoint

The central object remains stable while the active projection rotates through six perspectives.

VORTICAL–SYNERGETIC

Watch a dynamic field

Alternatives fluctuate around an attractor; field density, attraction and feedback are explicit state variables.

03 · Experiment studio

Reproduce a computer-model run

A reproducible run means that the same model version, seed and transition rules produce the same discrete state sequence. It does not establish empirical validity of the underlying theory. 



  






  


    
04 · Scientific integrity


    

      Source, implementation and evidence are separated.
    


    


      

        
Source-derived


        

          The four names, terminology and conceptual framing are presented as
          source-derived material.
        

      


      

        
Original implementation


        

          Numerical state variables, transition rules, particles, trajectories,
          metrics and visual metaphors are software choices in this website.
        

      


      

        
Evidence boundary


        

          These are educational simulations, not psychological tests,
          diagnoses, neuroscience models or validated measures of individual
          cognition.
        

      


    


    


      How to read the display

      

        A particle, score, trajectory or state label is an output of the
        computational model. It should not be treated as empirical evidence
        that the underlying framework predicts human cognition.
