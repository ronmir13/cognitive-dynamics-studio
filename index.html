Interactive Cognition Laboratory

Cognitive Dynamics

Cognitive Dynamics is an interactive laboratory containing four simulations: Dialectical–Algorithmic, Causal–Deterministic, Holographical–Panoramic, and Vortical–Synergetic cognition.

ORDERED CONTRADICTION-DRIVEN PROCESS

Dialectical–Algorithmic Cognition

State definition → thesis and antithesis → explicit contrast → contradiction → synthesis → rule → ordered algorithm → execution → feedback.

About the four Cognitive Dynamics simulations

The Dialectical–Algorithmic simulation represents cognition as an ordered contradiction-driven process moving from state definition through thesis, antithesis, contradiction, synthesis, rule, algorithm, execution and feedback.

The Causal–Deterministic simulation represents analytic and deductive cognition through observation, analysis, premises, causal chains, mechanisms, deductions, consequences and a singular result.

The Holographical–Panoramic simulation keeps one central object fixed while changing the perspective, projection, criterion and relation through which the object is examined.

The Vortical–Synergetic simulation represents fluctuation, circulation, alternative generation, screening, feedback and emergent concentration around an attractor.
